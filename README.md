# EYOUTH Future Mall Project

A multidisciplinary Future Mall project developed during the EYOUTH/DECI initiative, combining Python programming, web development, cybersecurity awareness, brand identity, and ESP32 smart garage simulation.

## Project Overview

This project was developed as part of the EYOUTH/DECI learning experience and brings together multiple practical tasks under one **Future Mall** concept.

The project covers programming, web development, cybersecurity awareness, visual branding, and hardware simulation through a series of practical tasks.

## Tasks

### Task 1 — Python Programming

Practical Python-based applications related to the Future Mall, including:

* Cashier program
* Product classification
* Visitors analysis

### Task 2 — Web Development

A Future Mall web page built using:

* HTML
* CSS

The page presents different mall sections and stores through a custom-designed interface.

### Task 3 — Cybersecurity Awareness

Cybersecurity-related materials and practical exercises covering topics such as:

* Security awareness
* Password security
* Protection practices

### Task 4 — Brand Identity

Visual identity work for the Future Mall, including:

* Logo development
* Brand colors
* Sketches and design process
* Promotional advertisement

### Task 5 — Smart Garage

An ESP32-based smart garage simulation developed using MicroPython and Wokwi.

The system includes:

* Entry and exit control
* LED indicators
* Garage capacity tracking
* Wiring and logic documentation

## Technologies & Tools

* Python
* HTML & CSS
* Excel
* ESP32
* MicroPython
* Wokwi
* Cybersecurity fundamentals
* Visual and brand design
